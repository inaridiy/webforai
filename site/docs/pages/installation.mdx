# Installation

The CLI needs no install at all — `npx webforai@latest <url>` prints Markdown to stdout.
See the [CLI reference](/cli). For the library, install `webforai`:

:::code-group

```bash [npm]
npm i webforai
```

```bash [pnpm]
pnpm i webforai
```

```bash [yarn]
yarn add webforai
```

:::

## Loader dependencies

Each [loader](/docs/loaders) needs its own extra setup; the core conversion functions need nothing more.

| loader | import | setup |
| --- | --- | --- |
| fetch | `webforai/loaders/fetch` | None. |
| Playwright | `webforai/loaders/playwright` | `playwright-core` is a peer dependency (installed with `webforai` by npm 7+ and pnpm; otherwise `npm i playwright-core`). Download a browser once with `npx playwright install chromium`. |
| Puppeteer | `webforai/loaders/puppeteer` | `npm i puppeteer` (downloads its own Chromium). |
| Cloudflare Browser Rendering | `webforai/loaders/cf-puppeteer` | `npm i @cloudflare/puppeteer` and a `browser` binding in your Wrangler config. |
