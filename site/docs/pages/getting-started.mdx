# Getting Started

## Overview

Welcome to webforai, a library designed to convert **HTML to Markdown** with simple utilities.
Whether you're working in a browser, Node.js, or even on Cloudflare Workers, webforai is your go-to tool for bridging between web and LLMs.

:::tip
webforai comes in three forms: this library, the [CLI](/cli) (`npx webforai-cli <url>`, a separate package), and a
[hosted API](/platform) that runs the browsers and proxies for you. This page covers the
library and the CLI; for the hosted API, [create an account](https://platform.webforai.dev/signup)
and follow the [platform quickstart](/platform#quickstart).
:::

## Quick Start (CLI)

The CLI needs no install. Convert any URL (or local HTML file) to Markdown in one command — the Markdown is printed to
stdout, so it can be piped, redirected, or captured:

```bash
npx webforai-cli@latest https://www.npmjs.com/package/webforai

# write to a file / emit machine-readable JSON instead
npx webforai-cli@latest https://www.npmjs.com/package/webforai -o webforai.md
npx webforai-cli@latest https://example.com --json | jq -r .markdown
```

Prefer prompts? `npx webforai-cli@latest -i` starts a guided interactive flow. The full flag
reference — including JavaScript rendering via Playwright or the
[hosted platform](/platform), and the Agent Skill for AI agents — lives on the
[CLI page](/cli).

## Installation

To use the library, install the package:

:::code-group

```bash [npm]
npm i webforai
```

```bash [pnpm]
pnpm i webforai
```

```bash [yarn]
yarn add webforai
```

:::

## Quick Start (Library)


::::steps

### Load HTML with utilities

Firstly, load HTML using the `loadHtml` utility. Using this function, you can get HTML from a URL in a simple way. It supports versions for **fetch**, **Playwright**, and **Puppeteer**.

:::code-group

```tsx [fetch] twoslash
import { loadHtml } from "webforai/loaders/fetch"; // [!code hl]

// Load html from url
const url = "https://www.npmjs.com/package/webforai";
const html = await loadHtml(url); // [!code hl]
```


```tsx [playwright] twoslash
// Before using the playwright loader, run `npm i playwright-core && npx playwright-core install chromium`
import { loadHtml } from "webforai/loaders/playwright"; // [!code hl]

// Load html from url
const url = "https://www.npmjs.com/package/webforai";
const html = await loadHtml(url); // [!code hl]
```

```tsx [puppeteer] twoslash
// Before using puppeteer loader, run `npm i puppeteer`
import { loadHtml } from "webforai/loaders/puppeteer"; // [!code hl]

// Load html from url
const url = "https://www.npmjs.com/package/webforai";
const html = await loadHtml(url); // [!code hl]
```

:::

:::warning
The `loadHtml` function is designed for ease of use and is not recommended for intensive use in production environments.
For production crawling, use the [hosted platform](/platform), which runs the browsers, proxies and queues for you.
:::

### Convert HTML to Markdown

Finally, convert HTML to Markdown with the `htmlToMarkdown` function.

```tsx 
import { htmlToMarkdown } from "webforai"; // [!code focus]
import { loadHtml } from "webforai/loaders/fetch";

// Load html from url
const url = "https://www.npmjs.com/package/webforai";
const html = await loadHtml(url); 

const markdown = htmlToMarkdown(html); // [!code focus]
```
