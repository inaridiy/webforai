**webforai platform** is a hosted crawl→Markdown API built on this library.
It takes a URL (or a whole site) and gives you back the same clean Markdown `htmlToMarkdown` produces,
without you running the browsers, proxies and queues yourself.

It is fully open source and self-hostable — the entire service is a single Cloudflare Worker in
[`apps/platform`](https://github.com/inaridiy/webforai/tree/main/apps/platform) of this repository.

```bash
curl -X POST https://platform.webforai.dev/v1/scrape \
  -H "Authorization: Bearer wfa_..." \
  -H "content-type: application/json" \
  -d '{ "url": "https://example.com/article" }'
```

Try it without an account on the [live demo](/#demo), or read the full [API reference](/platform/api-reference).

## Quickstart

1. **Create an account** at [platform.webforai.dev](https://platform.webforai.dev/signup) with
   your email address — we send a 6-digit sign-in code, no password needed —
   no card required, 1,000 credits per month are free.
2. **Mint an API key** on the [dashboard](https://platform.webforai.dev/dashboard). Keys look
   like `wfa_...` and are shown once at creation.
3. **Send the first request** — with curl (above), the [TypeScript client](/platform/client),
   or the [CLI](/cli). The [playground](https://platform.webforai.dev/playground) runs the
   same request from the browser and prints the equivalent curl.

## Clients

- **TypeScript** — [`webforai/platform`](/platform/client), a subpath of the `webforai`
  package: typed, dependency-free, with job polling and result paging built in.

  ```ts
  import { createPlatformClient } from "webforai/platform";

  const platform = createPlatformClient({ apiKey: process.env.WEBFORAI_API_KEY });
  const { markdown } = await platform.scrape({ url: "https://example.com", engine: "browser" });
  ```

- **CLI** — [`npx webforai`](/cli) uses the platform as a loader:

  ```bash
  WEBFORAI_API_KEY=wfa_... npx webforai https://example.com --engine browser --json
  ```

- **Anything that speaks HTTP** — the [API reference](/platform/api-reference) documents every
  route; authentication is one `Authorization: Bearer wfa_...` header.

## Capabilities

- **Scrape** — a single URL → Markdown + metadata. Synchronous, returns in one request.
- **Batch** — a list of URLs (≤100 per job) → Markdown per URL. Asynchronous.
- **Crawl** — a seed URL → recursive same-origin crawl with depth/page limits and
  include/exclude path patterns → Markdown per page. Asynchronous.

Asynchronous jobs run the exact same core logic on Cloudflare Workflows, so every page gets
durable execution and retries. Results are retained for 7 days and read back through the
[jobs API](/platform/api-reference#get-v1jobs).

## Engines

Every request picks how the HTML is acquired. Engines differ in what they can render, whether
they egress through a proxy, and what they cost in credits.

| engine | how it fetches | proxy | screenshot | credits |
| --- | --- | --- | --- | --- |
| `auto` (default) | Cheapest first, escalates to browser rendering when the page needs JavaScript | with region | yes | 1–2 (2–3 with a region) |
| `fetch` | Workers `fetch()` | no | no | 1 |
| `browser` | Browser rendering | no | yes | 2 |
| `proxy-fetch` | Plain fetch through a rotating proxy | yes | no | 2 |
| `proxy-browser` | Browser rendering behind the rotating proxy | yes | yes | 3 |

The default `auto` starts with a plain fetch and reruns in a browser only when the fetched HTML
turns out to be a client-rendered shell (or an anti-bot interstitial) — you are billed for the
engine that produced the result, and the response names it. Pin `fetch` for static HTML at a
guaranteed 1 credit, the `proxy-*` engines when a site blocks datacenter IPs or you need
[a specific region](/platform/api-reference#region), and either browser engine when the content
only exists after JavaScript runs.

## Options

- `screenshot` — PNG of the rendered page, stored in R2 and returned as an expiring URL.
  Browser engines only (`browser`, `proxy-browser`).
- `rehostImages` — downloads the images referenced by the resulting Markdown, re-uploads them to
  R2 with a TTL, and rewrites the Markdown to point at those copies.
- `convert` — extraction options passed straight through to webforai (`extractor` preset,
  `frontmatter`, `baseUrl`).

## Accounts and pricing

Accounts and API keys live on the [dashboard](https://platform.webforai.dev/dashboard); requests authenticate with
`Authorization: Bearer wfa_...`. Usage is metered in credits with **1,000 credits per month free** —
see [Billing](/platform/billing) for the full schedule.

## Self-hosting

Nothing here is proprietary. Deploy your own instance on your own Cloudflare account —
D1, KV, R2, Workflows and Browser Rendering bindings, plus your own rotating-proxy and Stripe
credentials. The setup steps live in the
[`apps/platform` README](https://github.com/inaridiy/webforai/tree/main/apps/platform#deploying-your-own-instance).

:::warning
The platform is a consumer of webforai, not a replacement for it. If you can run the conversion
yourself, [use the library](/getting-started) — it is faster, free, and has no rate limits.
:::
