## Decision log

- 2026-08-10: Single Worker + containers via create-nodejs-fn (user's own plugin) instead of a
  separate Node service — everything stays on Cloudflare, one deploy.
- 2026-08-10: D1 (not Postgres/Hyperdrive) — Cloudflare-native, simplest for OSS self-hosting.
- 2026-08-10: Single credits meter in Stripe, per-operation credit schedule in code.
- 2026-08-10: Keep repo's existing toolchain (biome/vitest/pnpm9); no Vite+ migration in this
  initiative.
- 2026-08-10: `@better-auth/stripe` has no metered support → plugin only for customer
  creation/webhooks; checkout/portal/meter events via stripe SDK directly.
- 2026-08-10: Workflow steps persist page results to KV inside the step (1 MiB step-return
  cap); crawl BFS state rebuilt deterministically from small step returns (`links` capped 200).
- 2026-08-10: Known pre-existing failures on baseline (NOT platform): 2 root vitest failures
  in packages/webforai (`html-to-markdown.test.ts` "Converting for good",
  `loaders/puppeteer.test.ts` custom-context) — present with the platform worktree stashed;
  belong to the in-flight extraction-overhaul WIP on main.
